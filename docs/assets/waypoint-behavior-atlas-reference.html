Technical schematic defining standardized mission navigation and sensor engagement behaviors for autonomous ISR assets. Reference: MIL-STD-ISR-011.

Launch

Ascent phase from ground station. Initiation of telemetry handoff and flight surface calibration.

BEH_ID: 002

Transit

High-speed movement between waypoints. Low sensor utility, prioritized efficiency.

BEH_ID: 003

Scout

Area sweep with dynamic path adjustment based on initial visual indicators.
