# Research Note: Cesium context layers (foliage and structures)

## Purpose
Contingency options for **vegetation (foliage)** and **built structures** in a CesiumJS mission planner when power-line ArcGIS endpoints are unavailable or irrelevant. Complements the Sunol Palantir bundle in `resources/palantir_sunol_aoi_upload/`.

## Status
- Validation status: `provisional`
- Last reviewed: `2026-05-03`
- Owner: project

## Design principles
- Prefer **WGS84 GeoJSON** for vectors; keep `source_name`, `source_url`, `retrieved_at`, and `provisional` on features where generated by scripts.
- **Fixture-first:** if a remote fetch fails, emit an empty `FeatureCollection` and keep the app usable (same pattern as [scripts/generate-palantir-bundle.mjs](../../scripts/generate-palantir-bundle.mjs)).
- **Power data** (CEC, HIFLD) is separate; failures there do not block buildings or vegetation.

## Ranked options: structures
| Priority | Source | Cesium use | Tradeoffs |
| --- | --- | --- | --- |
| 1 | **OpenStreetMap** `building=*` via [Overpass API](https://overpass-api.de/) | `GeoJsonDataSource`; extrude with `height` / `building:levels` if present | Coverage varies; same API as bundle generator |
| 2 | **Microsoft US Building Footprints** | Footprint polygons; constant or inferred extrusion | Large state files; clip to AOI; [license/attribution](https://github.com/microsoft/USBuildingFootprints) |
| 3 | **Cesium ion** OSM Buildings / **Google Photorealistic 3D Tiles** | `Cesium3DTileset` | Requires ion token; not offline-first |
| 4 | **Google Open Buildings** | Footprints | Global scale; verify license for redistribution |

**Default:** OSM/Overpass (generated as `osm/osm_buildings.geojson` in the bundle).

## Ranked options: foliage / vegetation
| Priority | Source | Cesium use | Tradeoffs |
| --- | --- | --- | --- |
| 1 | **OSM** `landuse` / `natural` (forest, wood, scrub, meadow, etc.) via Overpass | Semi-transparent green **Polygon** / **LineString** GeoJSON | Symbolic landcover, not biophysical survey |
| 2 | **NLCD** (National Land Cover Database) | `ImageryLayer` (WMS) or pre-tiled raster | Heavier; USGS [MRLC](https://www.mrlc.gov/) |
| 3 | **NAIP** or aerial basemap | Visual context only | No vector query of “forest” |

**Default:** OSM/Overpass (generated as `osm/osm_vegetation_landcover.geojson` in the bundle).

## Cesium mapping (implementation)
- **Vectors:** `GeoJsonDataSource.load(url, { clampToGround: true })` for foliage polygons; use **PolygonGraphics** with green fill + alpha. Buildings: **extrudedHeight** from `properties.height` (meters) if parseable, else `properties['building:levels'] * 3` (approximate), else a small constant for demo (e.g. 8 m).
- **Closed OSM ways:** The bundle generator converts **closed** ways to GeoJSON `Polygon`; open ways remain `LineString`.
- **Raster (NLCD later):** `WebMapServiceImageryProvider` or pre-rendered `SingleTileImageryProvider` / XYZ tiles clipped to the AOI.

## Limits
- OSM completeness differs by region; Sunol/Pleasanton Ridge mix of rural and suburban mapping.
- Multipolygon forest relations may be undercounted if only `way` queries are used; upgrade Overpass queries if large gaps appear on visual QA.
- **Node `fetch` to `overpass-api.de`** may return HTTP **406** unless a realistic **`User-Agent`** header is set (see [scripts/generate-palantir-bundle.mjs](../../scripts/generate-palantir-bundle.mjs)); bare Node defaults can yield HTML instead of JSON.
